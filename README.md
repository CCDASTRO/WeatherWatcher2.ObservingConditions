The WeatherWatcher2 Observing Conditions Driver is an ASCOM Observing Conditions driver for Windows that provides real-time weather and sky condition data to ASCOM-compatible astronomy applications. 
It is designed to work with several popular weather-monitoring data formats, allowing observatory automation software to use local weather information for imaging decisions and safety monitoring.

Supported Data Sources

The driver can read and parse data from:

realtime.txt generated by Cumulus MX
Data files generated by Boltwood Cloud Sensor II, etc.
WeatherWatcher2 output files such as currdat.lst, currdat.txt, and WeatherWatcher.txt

Reported ASCOM Observing Conditions

The driver can provide the following values through the ASCOM Observing Conditions interface:

Cloud cover
Sky temperature
Ambient temperature
Relative humidity
Dew point
Wind speed and gust speed
Wind direction
Rain / wetness indication
Barometric pressure
Sky quality (if available)
Time since last sensor update

Additional Features

Automatic detection of stale or outdated weather data
Unit conversion to ASCOM-standard units
User-configurable file path and refresh interval
Optional ASCOM trace logging
Setup dialog for configuring data source and options
Graceful handling of missing values
